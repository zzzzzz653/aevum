AEVUM — ПОЛНЫЙ ТЕХНИЧЕСКИЙ ПЛАН (v6.1 FINAL)
======================================================================
Проект Aevum: нейронный субстрат + эволюционная обёртка поверх Genesis.
Все блоки самодостаточны, содержат детали реализации.
======================================================================

0. МЕТА-ИНСТРУКЦИЯ И БАЗОВЫЕ ПРИНЦИПЫ
----------------------------------------------------------------------
Реализуется нейронный субстрат и эволюционная обёртка поверх физического
движка Genesis. Мир, физика, тело, суставы, мышцы, коллизии и сенсоры
УЖЕ РЕАЛИЗОВАНЫ. Строится всё, что выше: pressures, learning rules,
plasticity substrate, development engine, evolution engine, ecology,
растительная экосистема.

Главное правило: программируются ТОЛЬКО pressures, constraints, learning
rules, plasticity, development, evolution и detection systems. Никаких
готовых cognitive modules (нет PlanningModule, AttentionModule и т.п.).

Главный вызов: удержать систему в «живой зоне» между хаосом и
кристаллизацией на всех уровнях — нейронном, поведенческом, популяционном,
морфологическом и экосистемном.

Ключевые инженерные решения:
- Sub-tick нейросети (10 нейрошагов на 1 физшаг) для совместимости dt
- Exclusion-based Sleep Physics (тела удаляются из сцены в deep sleep)
- Seed-based Forking для Time-Machine Debugger
- Event-based Sparse Logging для наблюдаемости
- Стабилизированное локальное обучение Latent Encoder
- GPU-Resident Tensor Contract (все тензоры нейросети на GPU)

Новые механики v6.1:
- Гетерогенность нейронов (целевая сумма весов с индивидуальным bias)
- Базовый мышечный тонус (min сигнал + learned bias)
- Гистерезис в Global Workspace
- Ретроспективное усиление авторства (self_token ↔ action_token)
- DMN Interleaving (replay + симуляции)
- Thought Noise + Random Jump в потоке мыслей
- Экспоненциальное затухание старых мыслей
- Экосистема растений (self-expanding energy network + fungal communication)

Структура каталогов: aevum/core, aevum/embodiment, aevum/neural,
aevum/cognitive, aevum/evolution, aevum/ecology, aevum/observability,
aevum/experimentation, aevum/interfaces, aevum/config, aevum/utils.

ЧАСТЬ A: ОПЕРАЦИОННЫЙ КАРКАС (ИСПОЛНЕНИЕ)

A1. UNIFIED TICK SCHEDULER (ОБЯЗАТЕЛЬНО)
----------------------------------------------------------------------
Каждый тик симуляции разбит на фазы. Внутри фазы операции выполняются
строго последовательно. Никаких гонок. Результаты предыдущих фаз видны
последующим. Изменения весов, сделанные в фазе пластичности (Phase 6),
не влияют на распространение спайков в этом же тике (используются старые
веса).

A1.1 Суб-тиковая архитектура (Sub-tick Neural Stepping)
  - dt_physics = 0.01 с (100 Гц) — один вызов scene.step()
  - dt_neural = 0.001 с (1000 Гц) — 10 подшагов нейросети на 1 физшаг
  - Сенсорные данные (RGB, joint_positions, контакты) фиксируются
    в начале физического тика и НЕ меняются внутри подшагов (zero-order hold).
  - Моторные команды, сгенерированные на каждом подшаге, накапливаются:
    final_force = mean(forces[0..9]) — и применяются один раз перед
    следующим scene.step().
  - Конфигурация: N_neural_subticks = 10 в config/genesis.yaml.

Tick Pipeline (1 физический тик = 10 нейронных подшагов):

Phase 0: SENSORY INPUT & ENCODING (выполняется 1 раз в начале тика)
  0.1 Считать сырые данные сенсоров через GenesisEngineAdapter.get_sensors():
      vision: torch.Tensor [B, 64, 64, 4] float32 (RGBA)
      joint_pos: torch.Tensor [B, n_dofs] float32 (углы в радианах)
      joint_vel: torch.Tensor [B, n_dofs] float32
      contacts: list[dict] (link_id, pos, normal, force)
      imu_acc: torch.Tensor [B, 3] или None
      imu_gyro: torch.Tensor [B, 3] или None
  0.2 Применить ReceptorLayer.forward():
      vision → retina_preprocess (ON/OFF каналы, разность гауссиан)
      joint_pos → population_code (гауссовы рецептивные поля, k=8 на DOF)
      contacts → binary_flags [B, 4] (front/back/left/right)
      internal → [B, 2] (energy/max, damage/max)
      Выход: sensory_spike_probs [B, total_input_dim] float32 [0,1]
      total_input_dim = 64 (vision) + n_dofs*8 + 4 + 2
  0.3 Вычислить латентный вектор L_t через LatentEncoder.forward():
      L_t [B, latent_dim] float32, стандартно latent_dim = 32
      Внутри: bottleneck с L1-регуляризацией и шумовой injected noise.
  0.4 Сохранить L_{t-1} в HistoryBuffer (maxlen=100 тиков).

Phase 1: NEURAL DYNAMICS UPDATE (повторяется 10 раз за тик)
  Для sub_tick в range(N_neural_subticks):
  1.1 Извлечь спайки из SpikeQueue для времени sub_tick.
  1.2 Инжектировать входные токи: input_current = sensory_spike_probs
      на первом подшаге; на последующих sub_ticks сенсорный вход = 0.
  1.3 Обновить мембранные потенциалы: batch_ops.update_membrane(V, I, dt, rest)
    # Дополнение B25.3: стохастический резонанс
    noise_level = base_noise (0.01) * (1 + uncertainty_pressure * 3)
    # Бонус для "застрявших" нейронов (B25.3)
    time_since_last_spike = current_tick - last_spike_tick
    if time_since_last_spike > 500:
        noise_level *= 1 + min(3.0, (time_since_last_spike - 500) / 100)
    V += torch.randn_like(V) * noise_level * dt_neural

1.4 Проверить пороги: batch_ops.check_spikes(V, threshold, refractory)
    # Дополнение B25.5: нейромодуляция порога
    effective_threshold = threshold * (
        1 + 0.5 * serotonin - 0.3 * noradrenaline + 0.1 * acetylcholine
    )
    effective_threshold = clamp(effective_threshold, 0.7*threshold, 1.5*threshold)
    
    # Дополнение B25.7: энергетический барьер
    low_energy_mask = (neuron_energy < 0.1)
    effective_threshold[low_energy_mask] *= 3.0

1.5 Для спайкнувших нейронов: сбросить V, установить refractory_counter,
    обновить fatigue (B25.4), обновить avg_firing_rate (EMA).
    # Дополнение B25.4
    fatigue_level[spiked] += 1.0
    refractory_periods[spiked] = base_refractory (5) + (fatigue_level[spiked] // 2).int()
    
    # Дополнение B25.7
    neuron_energy[spiked] -= 0.001  # стоимость спайка
    neuron_energy = clamp(neuron_energy, 0.0, 2.0)
    
    # Дополнение B25.3
    last_spike_tick[spiked] = current_tick

1.6 Запланировать новые спайки в SpikeQueue с задержками:
    delay = base_delay + int(distance * time_per_unit)
    # Дополнение B25.6: Short-Term Depression
    # Фильтрация через release_probability происходит при доставке
  1.7 Каждые 100 подшагов: проверить Stability Contract MAX_GLOBAL_ACTIVITY.

Phase 2: MOTOR OUTPUT (последний подшаг)
  2.1 Вычислить firing_rates моторных нейронов (среднее за окно 10 тиков).
  2.2 MotorDecoder.decode(firing_rates) → raw_forces [B, n_dofs] float32
      в диапазоне [-max_force, +max_force].
  2.3 Нейронный CPG: осцилляция через взаимное ингибирование пулов
      (левые/правые конечности). Контакт стопы → инжекция тока +2.0 в
      соответствующий пул. Выход CPG: firing_rate за окно 10 тиков → [B, n_cpg].
      MotorControl.forward(cpg_output, motor_output, blend=0.5) → combined
  2.4 Motor Safety: ограничить изменение не более 10% за тик, clamp силами.
  2.5 Базовый мышечный тонус:
      Каждая мышца получает минимальный сигнал:
        base_tone = 0.2 + η_tone, где η_tone ~ Uniform(0, 0.05)
      К этому добавляется learned_bias — медленно накапливаемый через
      STDP и Reward Modulation сглаженный сигнал (EMA, α=0.001).
      Тонус обеспечивает:
      - Минимальную жёсткость суставов (предотвращает collapse)
      - Сохранение позы при отсутствии активных моторных команд
      - Базовый уровень, от которого обучение отталкивается
  2.6 Отправить финальные силы в Genesis: adapter.apply_actuators(body_id, forces).

Phase 3: WORLD STEP
  3.1 GenesisEngineAdapter.step_physics() → один вызов scene.step()
  3.2 Обновить EnergySystem:
      energy -= basal_metabolism (0.02)
      energy -= motor_energy (0.05 * mean(|forces|))
      energy -= neural_metabolism (0.0001 * N_neurons + 0.00001 * N_synapses
               + 0.001 * N_spikes)
  3.3 Обновить Plant Ecology (A20): фотосинтез, рост, сигналы.
  3.4 Проверить условие смерти: energy ≤ 0 или damage > critical.

Phase 4: PREDICTION & ERROR
  4.1 PredictorPool.forward(L_t, motor_commands) → L_pred_{t+1} [B, latent_dim]
      + confidence [B, 1] (обучен предсказывать exp(-error)).
  4.2 Вычислить prediction_error = MSE(L_pred_{t+1}, L_{t+1})
  4.3 Обновить скользящие средние: error_ema, confidence_ema, uncertainty_ema.
  4.4 Predictive Calibration: каждые 1000 тиков сравнить avg_confidence
      с actual_accuracy. При расхождении > 0.1 скорректировать bias
      confidence-нейронов на ±0.01.
  4.5 Обновить eligibility traces для TD(λ) (см. B11.1).

Phase 5: PHASE MANIFOLD UPDATE
  5.1 Вычислить все raw pressures из embodied статистики (A2.3):
      survival_pressure = 1.0 если energy < 0.1 * max_energy, иначе 0
      damage_pressure = damage / max_damage
      homeostatic_pressure = |energy/max_energy - 0.7| (отклонение от нормы)
      prediction_error_pressure = prediction_error / error_max
      novelty_pressure = 1 - cosine_sim(L_t, ближайший прототип)
      uncertainty_pressure = uncertainty_ema
      criticality_pressure = |branching_ratio - 1.0|
      entropy_pressure = max(0, entropy_floor - H_latent)
      social_pressure = mean(communication_activity) при других агентах рядом
  5.2 Преобразовать pressures → phase drives:
      raw_drives = W_pressure_to_drive @ pressures_vector
      (W = W_priors + W_adaptive, |W_adaptive| ≤ 0.2*|W_priors|)
  5.3 Обновить phase_state через динамику:
      drive[t+1] = drive[t] + drive_raw*(1-drive[t]) - decay*drive[t]
                   - Σ(inhibition[i,j] * drive[j]²)
                   + self_exc * drive[i]²*(1-drive[i])
                   + noise
  5.4 Применить Regulatory Latency: изменения в suppression_drive имеют
      задержку 200 тиков, entropy_destabilization — adaptive 50-500.
  5.5 Списать Regulatory Metabolic Cost с энергии агента.
  5.6 Применить Destabilization Debt: если destabilization_drive был >0.7,
      prediction_confidence *= 0.7, motor_precision *= 0.8 на 500 тиков.
  5.7 Anti-dominance/anti-extinction (A3).
  5.8 Вычислить neuromodulators = sigmoid(W_neuromod @ phase_state) [B, 6]:
      dopamine, serotonin, noradrenaline, acetylcholine, cortisol, adenosine
  5.9 Вычислить subnet_gains = sigmoid(W_subnet @ phase_state) [B, 10]:
      0=CPG, 1=PredictorPool, 2=LatentEncoder, 3=Planning, 4=VETO,
      5=EpisodicMemory, 6=SocialComm, 7=GlobalWorkspace, 8=MorphDreamer,
      9=ReflexLoops
  5.10 Обновить Ecological Latent Context:
       ecology_context [B, 8] = EMA(resource_stats, predator_trend, climate,
       social_density, terrain_difficulty) с τ=1000
  5.11 Если consolidation_drive > 0.8: применить Deep Sleep Exclusion
       (удалить тело из сцены). Если 0.5-0.8: перевести в Light Sleep
       (оставить тело пассивным, sparse sensory polling).
       При пробуждении: пересоздать тело и восстановить состояние
       (set_dofs_position, set_velocity).

Phase 6: PLASTICITY & STRUCTURAL ADAPTATION
  6.1 STDP update: stdp_batched.update(weights, pre_spike_times, post_spike_times,

  6.2 Hebbian update: hebbian_batched.update(weights, firing_rates, window=100,

  6.3 Eligibility trace decay: traces *= 0.95
  6.4 Если dopamine > 0.6: Reward Modulation: delta_w = lr * dopamine * traces
  6.5 TD(λ): temporal_credit.update(values, reward, gamma=0.95, lambda=0.8)
  6.6 Synaptic Scaling (каждые 1000 тиков):
      Целевая сумма входящих весов для нейрона i = 1.0 + ε_i,
      где ε_i ~ Uniform(-0.1, 0.1) зафиксировано при создании нейрона.
      Это создаёт «индивидуальность» нейронов и предотвращает
      формирование однородных пулов.
  6.7 Activity Homeostasis: baseline_excitability *= 1.01 если firing_rate
      < target_min; *= 0.99 если > target_max
  6.8 Structural Growth (каждые 500 тиков): growth_score = EMA(corr * error)
      > growth_threshold в течение 200 тиков → новый синапс
  6.9 Pruning (каждые 2000 тиков): weight < 0.001 в течение 5000 тиков → удалить
  6.10 Meta-Plasticity: effective = base / (tenure+1) × 0.1 если protected
       × 0.01 если identity_protected
  6.11 Identity Anchor eval (каждые 10000 тиков)
  6.12 MAX_TOPOLOGY_GROWTH: > 100 синапсов/тик → growth заморозить
  6.13 Timescale Separation Contract: проверка (A19)
6.14 BCM threshold update (B25.2):
    для каждого нейрона:
      bcm_threshold = 0.99 * bcm_threshold + 0.01 * (firing_rate ** 2)
    delta_w_bcm = 0.0005 * pre_activity * (post_activity - bcm_threshold_post)
    weights += delta_w_bcm

6.15 Local branching homeostasis (B25.8):
    для каждого нейрона:
      pre = pre_spikes_count[i]
      post = sum(post_spikes_count[j] for j in post_synaptic)
      local_branching = post / (pre + epsilon)
      local_branching_ema = 0.99 * old + 0.01 * local_branching
      
      if local_branching_ema > 1.5:
          # усилить тормозные связи
          для каждого исходящего синапса:
              if inhibitory: weight *= 1.05
              else: weight *= 0.95
      elif local_branching_ema < 0.5:
          # усилить возбуждающие связи
          для каждого исходящего синапса:
              if excitatory: weight *= 1.05
              else: weight *= 0.95

6.16 Neuron energy metabolism (B25.7):

    allocation = softmax(importance) * 0.01 * agent.energy
    neuron_energy += allocation
    neuron_energy += 0.0001  # базовый метаболизм

A2. PHASE MANIFOLD (НЕПРЕРЫВНАЯ ДИНАМИКА КОГНИТИВНЫХ РЕЖИМОВ)
----------------------------------------------------------------------
Pressures НЕ конкурируют как скаляры. Они индуцируют движение в
непрерывном пространстве dynamical regimes (phase manifold).

A2.1 Phase State Vector
  phase_state ∈ R^10, компоненты (drives) ∈ [0,1]:
    exploration_drive, exploitation_drive, defensive_drive,
    consolidation_drive, social_drive, developmental_drive,
    panic_drive, destabilization_drive, suppression_drive, recovery_drive

A2.2 Фазовая динамика
  drive[t+1] = drive[t]
             + activation_input * (1 - drive[t])
             - decay_rate * drive[t]
             - Σ(inhibition[i,j] * drive[j]²)
             + self_excitation * drive[i]² * (1 - drive[i])
             + η * noise
  A2.2.1 Attractor Sharpening: self_excitation term предотвращает
    «серую кашу» всех drives на уровне 0.3-0.5.

A2.3 От pressures к drives
  drive_activation = W_pressure_to_drive @ pressures_vector
  W = W_priors + W_adaptive, |W_adaptive[i,j]| ≤ 0.2 * |W_priors[i,j]|
  W_priors инициализирована разумными значениями (таблица ниже).

  Priors для W_priors:
    survival_pressure ↑  → panic_drive +0.8, defensive_drive +0.5
    damage_pressure ↑    → defensive_drive +0.7, panic_drive +0.3
    homeostatic_pressure → exploitation_drive +0.6
    prediction_error ↑   → exploration_drive +0.4, destabilization_drive +0.3
    novelty_pressure ↑   → exploration_drive +0.5
    uncertainty ↑        → exploration_drive +0.3, defensive_drive +0.2
    criticality > 1.2    → suppression_drive +0.8
    criticality < 0.8    → exploration_drive +0.4
    latent_entropy ↓     → destabilization_drive +0.7, exploration_drive +0.3
    social_pressure ↑    → social_drive +0.6
    energy < sleep_thr   → consolidation_drive +0.8, exploration_drive -0.3
    morphology_changed   → developmental_drive +0.7

A2.4 От phase_state к параметрам

  subnet_gains = sigmoid(W_subnet @ phase_state)        # 10 подсетей

  learning_rate_mod = 1 + 2*developmental + exploration - suppression

A2.5 Sleep as Continuous Drive
  consolidation_drive ∈ [0,1] непрерывно. Карта уровней:
  0-0.2: Awake (полный доступ к сенсорам/моторам)
  0.2-0.5: Drowsy/DMN (снижена моторика, DMN Interleaving 70/30)
  0.5-0.8: Light Sleep (пассивное тело, sparse sensing)
  0.8-1.0: Deep Sleep (тело удалено из симуляции, massive replay)

A2.6 Asynchronous Local Sleep
  Каждый агент спит сам. НЕТ глобального sleep scheduler.
  A2.6.1 Sleep Fidelity Scaling:
    | Уровень     | Физика          | Сенсоры        | Replay      | CPU cost |
    | Awake       | полная          | полные         | online only | 100%     |
    | Drowsy/DMN  | полная          | полные         | 70/30 mix   | 90%      |
    | Light Sleep | упрощённая      | sparse (1/10)  | medium      | 50%      |
    | Deep Sleep  | тело удалено    | polling (1/50) | massive     | 15%      |
  A2.6.2 Sleep Physics Policy:
    Deep Sleep: тело удаляется (scene.remove_entity), состояние сохраняется
    (qpos, qvel, позиция). При пробуждении: тело пересоздаётся,
    телепортируется в сохранённое состояние.
    Light Sleep: тело пассивно в сцене, моторы выключены.

A2.7 Regulatory Latency (АНТИ-OSCILLATION)

A2.8 Regulatory Metabolic Cost

A2.9 Destabilization Debt (АНТИ-НАРКОТИК)

A4. PREDICTION SUBSTRATE SPECIFICATION

PredictorPool: выделенный пул нейронов (64 нейрона).

A5. SALIENCY SPECIFICATION (ФОРМАЛЬНО)
----------------------------------------------------------------------
raw_saliency = w_n*novelty_i + w_e*pred_error_i + w_h*homeo_deviation_i + w_d*damage_i
Нормализация [0,1]. Top-K=8 проходят полностью, остальные ×0.2.
Lateral inhibition: подавление соседей. Temporal persistence: EMA с α=0.8.

Гистерезис фокуса (для Global Workspace, Roadmap 5.1):
  - Уже активный слот имеет коэффициент удержания 0.8
    (его saliency умножается на 1.25 для сравнения с новыми кандидатами)
  - Новый кандидат имеет коэффициент 1.0
  - Чтобы вытеснить текущий процесс из фокуса, новый должен превысить
    его effective_saliency = saliency * retention_coefficient

A6. IDENTITY ANCHORS (ФОРМАЛЬНО)
----------------------------------------------------------------------
Детекция: группы нейронов с cosine_similarity > 0.9 на T_anchor=10000 тиков.
Требуется значимость: влияние на действия или предсказания.
Защита: пластичность ×0.01, pruning только при катастрофическом падении.
Пересмотр при смене среды (медленно, с гистерезисом).

A6.4 Ретроспективное усиление «Я» (Retrospective Agency Attribution)
  После выполнения действия:
  - Если self_error (predicted_self_state vs actual_self_state) < 0.1:
    связь self_token ↔ action_token усиливается через eligibility trace
    с коэффициентом 0.2 (Δw = 0.2 * eligibility * (1 - self_error))
  - Если self_error > 0.3: усиления не происходит
    (действие вышло из-под контроля, не «моё»)
  
  Это создаёт накопление «авторства» над успешными действиями.
  Действия с низкой ошибкой предсказания своего состояния
  маркируются как «мои» и формируют основу self-model.

A20. PLANT ECOLOGY SUBSYSTEM (РАСТИТЕЛЬНАЯ ЭКОСИСТЕМА)
----------------------------------------------------------------------
Базовый принцип: растение — не объект, а self-expanding energy network.
Растения образуют отдельный тип жизни с другой динамикой времени,
стратегией выживания и формой распределённого интеллекта.

A20.1 Три слоя растения

  A. STRUCTURE LAYER (жёсткий каркас)
    - Ветви, стебли, ствол — rigid bodies в Genesis
    - Функция: удержание листвы, подъём к свету, защита от collapse
    - Параметры: structural_integrity, max_supported_leaf_mass,
      wood_density, growth_rate
    - Ограничение: max_supported_leaf_mass ∝ structural_integrity

  B. LEAF LAYER (энергосбор)
    - НЕ rigid bodies — параметрические поверхности
    - Параметры: leaf_area, leaf_density, light_efficiency,
      photosynthesis_rate, damage_state
    - Самозатенение: effective_leaf_area ≤ total_leaf_area
      (перекрывающиеся листья снижают эффективность)

  C. ROOT LAYER (сбор воды/минералов)
    - Параметры: root_depth, root_spread, water_absorption_rate,
      nutrient_efficiency

A20.2 Energy Economy

  Днём (light_level > 0):
    energy_gain = light_level
                * effective_leaf_area
                * photosynthesis_efficiency
                * temperature_factor

  Ночью (light_level = 0):
    energy_gain = 0
    energy_consumption = maintenance_cost (базальный метаболизм)

  maintenance_cost ∝ total_biomass (структура + листья + корни)
  transport_cost ∝ height (доставка воды от корней к кроне)

A20.3 Light Competition (главный pressure)

  - Растения конкурируют за свет через вертикальный рост
  - Высокие растения затеняют низкие
  - Самозатенение ограничивает бесконечное расширение кроны
  - Эмерджентные ярусы: canopy → understory → forest floor

A20.4 Growth Buds (распределённый рост)

  Растение имеет growth_nodes — активные точки роста.
  Каждый bud принимает локальные решения на основе градиентов:

  | Условие                 | Решение бутона                       |
  |-------------------------|--------------------------------------|
  | light_gradient ↑ вверх  | vertical_growth_bias ↑               |
  | water_deficit ↑         | root_growth_bias ↑                   |
  | structural_stress ↑     | wood_thickness ↑ (укрепление)        |
  | free_light_pocket рядом | lateral_branch → туда                |
  | энергия избыточна       | новый leaf_cluster / reproductive bud|

  Рост НЕ централизован. Каждый bud автономен.

A20.5 Fungal Communication Network (распределённая сигнальная сеть)

  Каждое растение может излучать сигналы в радиусе fungal_radius:

  Типы сигналов:
    stress_signal:     "я в стрессе" (засуха, болезнь)
    water_signal:      "здесь есть вода"
    light_signal:      "здесь хороший свет" / "здесь тень"
    danger_signal:     "повреждение/пожар"

  Характеристики сигналов:
  - Noisy: добавляется гауссов шум (σ = 0.2 * signal_intensity)
  - Delayed: задержка ∝ distance (1 тик на 0.1 единицы расстояния)
  - Local: ограничены fungal_radius
  - Low bandwidth: 1 сигнал в 10-50 тиков
  - Costly: signal_cost = radius² * intensity * 0.001 energy

  Получатель интерпретирует сигнал как pressure modulation:
  - received_water_stress ↑ → root_growth_bias ↑
  - received_shade_signal ↑ → vertical_growth_bias ↑

  ВАЖНО: сигналы — НЕ команды. Это pressure modulation.
  Растение само решает, как реагировать.

A20.6 Эволюция грибной сети

  Мутируют:
  - fungal_radius: [0.1, 5.0]
  - signal_types: какие сигналы излучать/принимать
  - signal_cost_efficiency: сколько энергии на единицу радиуса
  - signal_decay: как быстро затухает с расстоянием
  - signal_sensitivity: порог обнаружения

A20.7 Размножение

  Seed packet содержит:
    genome (параметры развития)
    stored_energy (начальный запас)
    dispersal_bias (ветер/животные/вода)
    dormancy_parameters (сколько ждать благоприятных условий)

  Способы распространения:
  - Пассивное падение (рядом с родителем)
  - Ветер (дальность ∝ высота родителя)
  - Животные (перенос через поедание/прилипание — Roadmap C)
  - Вода (вдоль водных потоков)

A20.8 Эмерджентные феномены

  Ожидаемые типы растений:
  🌱 Низкие быстрые колонизаторы (r-стратегия)
  🌲 Высокие медленные деревья (K-стратегия)
  🌿 Лианы (растут на чужих каркасах)
  🍄 Грибные cooperative clusters (обмениваются сигналами)
  🌵 Экономные drought-виды (минимальная leaf_area, глубокие корни)
  🌾 Агрессивные световые колонизаторы (быстрый рост, подавление соседей)

A20.9 Защита от эксплойтов

  ПРОБЛЕМА 1: Infinite vertical towers
    Решение: transport_cost ∝ height² (квадратичный штраф за высоту)
    Выше некоторой высоты — energy_balance становится отрицательным

  ПРОБЛЕМА 2: Infinite leaf expansion
    Решение: maintenance_cost ∝ leaf_area + самозатенение
    Дополнительные листья снижают effective_leaf_area существующих

  ПРОБЛЕМА 3: Signal spam
    Решение: communication_cost ∝ radius² * intensity
    Частые/дальние сигналы истощают энергию

  ПРОБЛЕМА 4: Forest lock-in monoculture
    Решение: seasons (циклическая нагрузка), stochastic disturbances
    (пожары, болезни), climate oscillations (медленные изменения)

После спайка: V = resting_potential, refractory_counter = refractory_period,
  fatigue += 1.0, avg_firing_rate = 0.99*old + 0.01*spike_indicator.
Activity Homeostasis: каждые 1000 тиков, если avg_firing_rate > target_max
  → baseline_excitability *= 0.99; если < target_min → *= 1.01.

B2.1 PERFORMANCE CONSTRAINT
  Все операции над тензорами через aevum/neural/dynamics/batch_ops.py.
  Никаких Python-циклов по нейронам в production.
  Даже для B=1: тензор имеет форму [1, N].

  tenures: torch.Tensor [N, N] int32

depletion_counter: torch.Tensor [N, N] int32        # STD
Задержка: delay = base (1 sub_tick) + int(L2_distance(pre, post) * 0.5).

B4. НЕЙРОННЫЙ ГРАФ
----------------------------------------------------------------------
Файл: aevum/neural/graph/topology.py.

Структура:
  neurons: SoA буферы (B2)
  synapses: sparse matrix + arrays (B3)
  adjacency_out: dict[int, list[int]] (для быстрой доставки спайков)
  adjacency_in: dict[int, list[int]]
  spike_queue: list[tuple[int, torch.Tensor, torch.Tensor]]
    [(delivery_subtick, pre_mask [B, 1], post_indices [K])]
  active_neurons_mask: torch.Tensor [B, N] bool

Инициализация топологии: create_initial_topology() создаёт связи:
  - Сенсорные нейроны → интернейроны: 50% connectivity, weight ~ N(0, 0.1)
  - Интернейроны → интернейроны: 20% connectivity, weight ~ N(0, 0.05)
  - Интернейроны → моторные: 50% connectivity, weight ~ N(0, 0.1)
  - 20% связей помечены как inhibitory (weight *= -1).
Стоимость роста: cost = 0.1 + 0.01 * distance_euclidean.

B4.3 ACTIVE SUBNETWORKS PER PHASE STATE
  Функция: subnet_gains = sigmoid(W_subnet @ phase_state)  # [B, 10]
  gain < 0.1: подсеть заморожена (веса не обновляются, спайки не генерируются).
  gain 0.1-0.5: inference only (спайки идут, но plasticity = 0).
  gain > 0.5: полная функциональность.

B5. ПЛАСТИЧНОСТЬ
----------------------------------------------------------------------
B5.1 STDP (векторизованный, модулированный)
  Файл: aevum/neural/plasticity/stdp.py.
  Алгоритм:
    Индексы активных pre/post нейронов из spike_queue.
    delta_t = pre_spike_times - post_spike_times
    mask = |delta_t| < window (20 subticks)
    delta_w = where(delta_t > 0, A_plus*exp(-delta_t/tau), -A_minus*exp(delta_t/tau))
    delta_w *= dopamine_factor  # модуляция: dopamine*2 + 0.5
    weights += 0.005 * delta_w

B5.2 Hebbian
  Файл: aevum/neural/plasticity/hebbian.py.
  correlation = (firing_rates.T @ firing_rates) / window_size (100)
  delta = 0.001 * (correlation - 0.01)
  weights += delta

B5.3 Reward Modulation
  Если dopamine > 0.6: delta_w = 0.001 * dopamine * eligibility_trace

B5.4 Synaptic Scaling (с гетерогенностью)
  Каждые 1000 тиков: сумма входящих весов нормализуется.
  Целевая сумма для нейрона i = 1.0 + ε_i, где ε_i ~ Uniform(-0.1, 0.1)
  зафиксировано при создании нейрона и не меняется.
  
  Это создаёт «индивидуальность» нейронов: одни естественно более
  возбудимы (сумма > 1.0), другие — менее (сумма < 1.0). Предотвращает
  формирование однородных пулов и способствует спонтанной дифференциации.

B5.5 Structural Growth
  growth_score = EMA(corr * error). > 0.05 sustained 200 тиков → новый синапс.

B5.6 Pruning
  Каждые 2000 тиков: weight < 0.001 sustained 5000 тиков → удалить.

B5.7 Meta-Plasticity
  effective = base_plasticity / (tenure + 1)
  × 0.1 если protected, × 0.01 если identity_protected.

B10. REPRESENTATION LEARNING
----------------------------------------------------------------------
B10.1 Latent Encoder (Bottleneck)
  Сенсоры → линейный слой [total_dim, 64] → ReLU → [64, 32].
  L1 регуляризация на выходе (λ=0.001).
  Добавление шума: noise ~ N(0, 0.01) во время обучения.

B10.2 Contrastive Predictive Coding
  Притяжение L_t и L_{t+1} (cosine_sim → +1). Отталкивание случайных пар.

B10.3 Temporal Coherence: loss += 0.01 * ||L_t - L_{t-1}||².

B10.4 Multimodal Binding: если зрение и проприоцепция одновременно
  активны → притяжение их partial latents.

B10.5 Sparse Coding: L1 = 0.001 * Σ|latent_i|.

B10.6 СТАБИЛИЗИРОВАННОЕ ЛОКАЛЬНОЕ ОБУЧЕНИЕ
  a) Predictive Target Injection: L_actual_{t+1} инжектируется как ток
     в энкодер, нейроны, приблизившие латент к целевому, получают STDP+.
  b) Sensory Reconstruction: 8 случайных проекций [32, total_dim] фикс.,
     ошибка реконструкции усредняется → нейромодулятор.
  c) CPC через линейный считыватель: считыватель [32, total_dim] обучается
     online δ-правилом, его ошибка → модулятор.
  d) Batch Normalization: running mean и var по времени. При |latent_i| > 3σ
     → инжекция шума.
  e) Warm-up: learning_rate растёт от 0.001 до 0.01 первые 1000 тиков.

B10.7 Predictive Entropy Floor
  Каждые 100 тиков: H_latent оценка (k-d tree, K=32 ячейки).
  Если H < 1.0 бит → destabilization_drive активируется.

B11. TEMPORAL CREDIT ASSIGNMENT

Hierarchical Replay: приоритет = |δ|.

B25. MICROLEVEL NEURONAL DYNAMICS (ДОПОЛНЕНИЕ К B2-B5)
----------------------------------------------------------------------
Низкоуровневые физиологичные механизмы, обеспечивающие самоорганизацию
без глобальных хардкодных ограничителей.

B25.1 МИКРОКОЛОНКИ И ЛАТЕРАЛЬНОЕ ТОРМОЖЕНИЕ
  Группировка нейронов в микроколонки (по умолчанию 8-12 нейронов на колонку).
  
  Параметры инициализации:
    column_radius = 0.1 (в нормализованных координатах)
    column_size = 8 + randint(0, 4)
    
  Правила связей внутри колонки:
    - Внутри: высокая возбуждающая связность (50% вероятности)
    - Между соседними колонками (distance < 2*radius): латеральное торможение
    - Латеральные связи: weight = -0.3 ± 0.1, задержка = 1 sub_tick
  
  Механизм "победитель":
    В каждой колонке каждые 10 тиков выбирается нейрон с max(firing_rate).
    Он получает временный бонус к baseline_excitability (×1.2 на 5 тиков).
    Остальные получают торможение от него через латеральные связи.
  
  Эффект: естественная конкуренция за представление признаков,
  предотвращает "обобщённый шум" и способствует специализации.

B25.2 BCM-ПРАВИЛО (BIENENSTOCK-COOPER-MUNRO)
  Адаптивный порог вместо глобальной гомеостазы.
  
  Для каждого нейрона i:
    θ_i (bcm_threshold) — скользящее среднее квадрата его активности.
    Обновление в конце каждого тика:
      θ_i = 0.99 * θ_i + 0.01 * (firing_rate_i ** 2)
    
    Модификация весов (дополнительно к STDP):
      Δw_BCM = η_bcm * pre_activity * (post_activity - θ_post)
      η_bcm = 0.0005 (в 2 раза ниже STDP)
  
  Эффект:
    - Нейроны с хронически высокой активностью повышают порог (десенсибилизация)
    - Долго молчавшие нейроны становятся чувствительными к слабым сигналам
    - Автоматическое разделение ролей без хардкодных целевых сумм
  
  Конфиг: config/policies/bcm.yaml
    bcm_learning_rate: 0.0005
    bcm_tau: 0.99
    bcm_update_interval: 1 (каждый тик)

B25.3 СТОХАСТИЧЕСКИЙ РЕЗОНАНС (ШУМ КАК РЕСУРС)
  Шум в мембранный потенциал модулируется неопределённостью.
  
  В Phase 1.3 (обновление мембранного потенциала):
    noise_level = base_noise * (1 + uncertainty_pressure * 3)
    noise = torch.randn_like(V) * noise_level * dt_neural
    V += noise
    
    Дополнительно: нейроны без спайков > T_quiet получают повышенный шум:
      if refractory_counter == 0 and last_spike_time > 500 (тиков):
        noise *= 1 + min(3.0, (time_since_last_spike - 500)/100)
    
    Спайк сбрасывает накопленный бонус к шуму.
  
  Эффект:
    - При неопределённости мозг "щупает" пространство
    - "Застрявшие" нейроны получают шанс вырваться из локального минимума
    - Нет хардкодного random_jump — всё через физику шума

B25.4 ACTIVITY-DEPENDENT РЕФРАКТЕРНОСТЬ
  Рефрактерный период растёт с усталостью нейрона.
  
  Структура (добавить в B2):
    fatigue_level: torch.Tensor [B, N] float32 (0..10)
    refractory_periods: torch.Tensor [B, N] int32 (dynamic)
  
  Обновление после спайка:
    fatigue_level += 1.0
    refractory_period = base_refractory (5) + int(fatigue_level / 2)
  
  Каждый тик (если нейрон не спайкал):
    fatigue_level *= 0.998 (медленное восстановление, τ=500 тиков)
  
  Эффект:
    - Предотвращает pathological bursting
    - Нейрон, спайкающий на 1000 Гц, получает долгий рефрактер (до 10+)
    - Естественный gain control без MAX_GLOBAL_ACTIVITY

B25.5 НЕЙРОМОДУЛЯЦИЯ СПАЙКОВОГО ПОРОГА
  Серотонин и норадреналин динамически меняют порог возбуждения.
  
  В Phase 1.4 (проверка порога):
    effective_threshold = threshold * (
        1 
        + 0.5 * serotonin      # повышает порог → устойчивость
        - 0.3 * noradrenaline  # снижает порог → возбудимость
        + 0.1 * acetylcholine  # небольшое снижение (внимание)
    )
    effective_threshold = clamp(effective_threshold, 0.7*threshold, 1.5*threshold)
  
  Эффект:
    - Высокий норадреналин → режим сканирования, лёгкое возбуждение
    - Высокий серотонин → жди чёткого сигнала, не дёргайся на шум
    - Связывает глобальное состояние с микроуровнем

B25.6 КРАТКОВРЕМЕННАЯ СИНАПТИЧЕСКАЯ ДЕПРЕССИЯ (STD)
  Пресинаптическое истощение — чувствительность к темпу спайков.
  
  Структура синапса (добавить в B3):
    release_probability: torch.Tensor [N, N] float32 (init 0.5)
    depletion_counter: torch.Tensor [N, N] int32 (init 0)
  
  При каждом пресинаптическом спайке:
    if release_probability > random():
        spike_передаётся
        release_probability *= 0.95
        depletion_counter += 1
    else:
        spike_теряется
    
    Восстановление каждый тик (независимо от активности):
        release_probability += (0.05 - 0.001 * depletion_counter)
        release_probability = min(0.95, release_probability)
        depletion_counter = max(0, depletion_counter - 1)
  
  Эффект:
    - Серия из 10 спайков за 5 мс: release_probability падает с 0.5 до 0.5*0.95^10 ≈ 0.3
    - Последующие спайки с высокой вероятностью не пройдут
    - Кодирует "внезапность" и "темп", а не просто "факт спайка"
    - Естественное подавление runaway на микроуровне

B25.7 ЭНЕРГЕТИЧЕСКИЙ БЮДЖЕТ НЕЙРОНА
  У каждого нейрона свой энергетический резерв, метаболическая поддержка.
  
  Структура (добавить в B2):
    neuron_energy: torch.Tensor [B, N] float32 (init 1.0)
    energy_demand: torch.Tensor [B, N] float32 (0.001 per spike)
  
  При попытке спайка (Phase 1.4):
    if neuron_energy < 0.1:
        effective_threshold *= 3.0  # почти невозможно спайкнуть
    else:
        neuron_energy -= energy_demand
        # спайк происходит
  
  Метаболическая поддержка (каждый тик):
    global_energy_pool = sum(agent.energy)  # из EnergySystem
    # Перераспределение в пользу важных нейронов
    importance = saliency + prediction_error + (1 - neuron_energy)
    allocation = softmax(importance) * 0.01 * global_energy_pool
    neuron_energy += allocation
    
    Базовое восстановление: neuron_energy += 0.0001 (минимальный метаболизм)
    neuron_energy = clamp(neuron_energy, 0.0, 2.0)
  
  Эффект:
    - "Кричащие" нейроны тратят энергию, "молчаливые" накапливают
    - Важные нейроны (высокая saliency) получают поддержку
    - Связь между физической усталостью и вычислениями

B25.8 ЛОКАЛЬНЫЙ BRANCHING RATIO
  Каждый нейрон контролирует свою "влиятельность".
  
  Для каждого нейрона i:
    pre_spikes[t] = число спайков i
    post_spikes[t] = сумма спайков всех постсинаптических нейронов j
    local_branching[t] = post_spikes[t] / (pre_spikes[t] + epsilon)
    
    Обновление скользящего среднего:
      local_branching_ema = 0.99 * old + 0.01 * current
    
    Гомеостаз (каждые 100 тиков):
      if local_branching_ema > 1.5:
          # нейрон слишком влиятельный — усилить его тормозные связи
          for each outgoing synapse:
              if inhibitory: weight *= 1.05
              else: weight *= 0.95
      elif local_branching_ema < 0.5:
          # нейрон-изгой — усилить его возбуждающие связи
          for each outgoing synapse:
              if excitatory: weight *= 1.05
              else: weight *= 0.95
  
  Эффект:
    - Предотвращает диктатуру одного нейрона
    - "Мёртвые" нейроны получают шанс вернуться в игру
    - Самоорганизующаяся сеть без хардкодного pruning по весу
